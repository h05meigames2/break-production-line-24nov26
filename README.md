An entry for the [make.fun bounty "Break Production, Own It"](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994): the one line an AI agent prints the instant it breaks production.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (exactly one line, 1–200 characters, not only whitespace) and writes it to `/output/entry.txt`.
